# NOTICE

WarPrime is an unofficial rebrand of the OpenWF client bootstrapper.

## Upstream projects

- OpenWF — https://onlyg.it/OpenWF
  - Bootstrapper-Setup: https://onlyg.it/OpenWF/Bootstrapper-Setup
  - Client drop-in scripts, translations and assets
- warframe-dll — https://github.com/spaceninjaserver/warframe-dll
- Soup — https://github.com/calamity-inc/Soup
- Pluto — https://github.com/PlutoLang/Pluto
- Sideloadify — https://github.com/Sainan/Sideloadify
- Warframe cache tools — https://github.com/Sainan/warframe-cache-tools

## What was changed

- Replaced the user-visible name `OpenWF` with `WarPrime` in source code, overlay,
  window titles, in-game menu labels, HTML UI, version resources and scripts.
- Renamed the runtime data directory `OpenWF/` to `WarPrime/`.
- Repointed download and update URLs to `raw.githubusercontent.com/kekyoko/warprime`.
- Rebuilt `dwmapi.dll` and `WarPrime Setup.exe` from the modified sources.

Internal identifiers (e.g. `owf_*`, `OWF_*`, file names such as `Hotfix.owf`) were intentionally
left unchanged for compatibility.
